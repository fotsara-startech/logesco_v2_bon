# Script Vidéo 06 — Fournisseurs et Approvisionnements

**Durée estimée : 6-7 minutes**
**Public cible : Gestionnaires, Responsables achats**

---

## SCRIPT AUDIO (à lire pour ElevenLabs)

Dans cette vidéo, nous allons voir comment gérer vos fournisseurs et vos commandes d'approvisionnement dans LOGESCO v2.

### Partie 1 — Gérer les fournisseurs

Dans le menu principal, cliquez sur le module Fournisseurs.

Vous voyez la liste de tous vos fournisseurs. Pour chaque fournisseur, vous avez son nom, ses coordonnées, et le solde de votre compte avec lui.

Pour ajouter un nouveau fournisseur, cliquez sur le bouton Nouveau fournisseur.

Remplissez le formulaire avec les informations du fournisseur : son nom ou raison sociale, son numéro de téléphone, son adresse, et toute autre information utile.

Enregistrez pour valider la création.

La fiche fournisseur vous donne accès à l'historique de toutes vos transactions avec ce fournisseur : les commandes passées, les livraisons reçues, et les paiements effectués.

Si vous avez des achats à crédit auprès d'un fournisseur, le solde de votre compte indiquera ce que vous lui devez.

### Partie 2 — Créer une commande d'approvisionnement

Pour commander des marchandises auprès d'un fournisseur, accédez au module Approvisionnements.

Vous voyez la liste de toutes vos commandes avec leur statut : en attente, reçue, ou annulée.

Pour créer une nouvelle commande, cliquez sur Nouvelle commande.

Première étape : sélectionnez le fournisseur auprès duquel vous passez la commande.

Deuxième étape : ajoutez les produits à commander. Recherchez chaque produit et indiquez la quantité souhaitée. Le logiciel affiche le prix d'achat habituel pour vous aider.

Troisième étape : définissez la date de livraison prévue. Cela vous permettra de suivre si la livraison arrive à temps.

Quatrième étape : choisissez le mode de paiement : comptant ou à crédit.

Cinquième étape : ajoutez des notes si nécessaire, par exemple des instructions spéciales pour le fournisseur.

Cliquez sur Enregistrer pour créer la commande.

### Partie 3 — Les suggestions d'approvisionnement

LOGESCO v2 dispose d'une fonctionnalité très pratique : les suggestions d'approvisionnement.

Le logiciel analyse automatiquement votre stock et identifie les produits dont le niveau est bas ou qui ont atteint leur seuil d'alerte.

Accédez à la section Suggestions dans le module Approvisionnements.

Vous verrez une liste des produits à réapprovisionner avec les quantités suggérées basées sur votre historique de ventes.

Vous pouvez sélectionner les produits qui vous intéressent et créer directement une commande à partir de ces suggestions, ce qui vous fait gagner beaucoup de temps.

### Partie 4 — Réceptionner une commande

Lorsque votre fournisseur livre la marchandise, vous devez enregistrer la réception dans le logiciel.

Accédez à la commande concernée dans la liste des approvisionnements.

Cliquez sur Réceptionner la commande.

Vérifiez les quantités reçues. Si la livraison est partielle, vous pouvez ajuster les quantités.

Confirmez la réception. Le logiciel met automatiquement à jour votre stock en ajoutant les quantités reçues.

Si le paiement est à crédit, le montant est enregistré dans votre compte fournisseur.

### Partie 5 — Exporter une commande

Vous pouvez exporter votre bon de commande en PDF pour l'envoyer à votre fournisseur.

Depuis la fiche de la commande, cliquez sur le bouton d'export PDF.

Le document est généré avec tous les détails de la commande et peut être partagé par email ou imprimé.

Dans la prochaine vidéo, nous verrons la gestion de la caisse et des sessions de caisse.
