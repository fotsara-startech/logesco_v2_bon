# Script Vidéo 03 — Gestion des Ventes

**Durée estimée : 6-7 minutes**
**Public cible : Caissiers, Vendeurs, Gestionnaires**

---

## SCRIPT AUDIO (à lire pour ElevenLabs)

Dans cette vidéo, nous allons voir comment enregistrer une vente dans LOGESCO v2. C'est l'une des fonctions les plus utilisées au quotidien.

### Partie 1 — Accéder au module Ventes

Dans le menu principal, cliquez sur le module Ventes.

Vous arrivez sur la liste de toutes les ventes enregistrées. Vous pouvez voir la date, le client, le montant total, et le statut de chaque vente.

Pour créer une nouvelle vente, cliquez sur le bouton Nouvelle vente en haut à droite.

### Partie 2 — Créer une vente

L'écran de création de vente s'ouvre. Voici comment procéder étape par étape.

Première étape : sélectionner le client. Cliquez sur le champ Client et recherchez le nom du client dans la liste. Si le client n'existe pas encore, vous pouvez le créer directement depuis cet écran.

Si la vente est faite à un client de passage sans compte enregistré, vous pouvez laisser ce champ vide ou sélectionner un client générique.

Deuxième étape : ajouter les produits. Cliquez sur le champ de recherche de produits et tapez le nom ou la référence du produit que vous souhaitez vendre.

Sélectionnez le produit dans la liste qui s'affiche.

Indiquez la quantité souhaitée. Par défaut, la quantité est de 1. Modifiez-la selon le besoin.

Le produit est ajouté au panier avec son prix unitaire et le sous-total calculé automatiquement.

Répétez cette opération pour chaque produit à ajouter à la vente.

Troisième étape : appliquer une remise si nécessaire. Si vous souhaitez accorder une remise à votre client, vous pouvez l'appliquer sur un produit spécifique ou sur le total de la vente. Saisissez le montant de la remise dans le champ prévu.

Quatrième étape : vérifier le total. En bas de l'écran, vous voyez le récapitulatif : le sous-total, la remise éventuelle, la TVA si applicable, et le montant total à payer.

Cinquième étape : choisir le mode de paiement. Sélectionnez le mode de paiement : espèces, virement, ou crédit. Si le client paie en espèces, saisissez le montant reçu et le logiciel calculera automatiquement la monnaie à rendre.

Si vous choisissez le crédit, le montant sera enregistré dans le compte client et apparaîtra comme une dette à régler ultérieurement.

Sixième étape : confirmer la vente. Cliquez sur le bouton Confirmer la vente.

Le logiciel enregistre la vente, met à jour le stock automatiquement, et génère un reçu.

### Partie 3 — Le reçu

Après confirmation, vous avez la possibilité d'imprimer le reçu ou de le prévisualiser à l'écran.

Le reçu contient toutes les informations importantes : le nom de votre entreprise, la date et l'heure, la liste des produits vendus, les quantités, les prix, et le total.

Si vous avez configuré votre logo et votre slogan dans les paramètres de l'entreprise, ils apparaîtront également sur le reçu.

### Partie 4 — Consulter et annuler une vente

Pour consulter le détail d'une vente passée, cliquez sur la vente dans la liste.

Vous verrez tous les détails : les produits, les quantités, le client, le mode de paiement, et la date.

Si vous devez annuler une vente, cliquez sur l'option d'annulation. Attention : l'annulation d'une vente remet automatiquement les quantités en stock. Cette action est irréversible, donc assurez-vous d'en avoir besoin avant de confirmer.

### Partie 5 — Filtrer les ventes

Pour retrouver une vente spécifique, utilisez les filtres disponibles : par date, par client, ou par montant.

Vous pouvez également utiliser la barre de recherche pour trouver une vente rapidement.

Dans la prochaine vidéo, nous verrons comment gérer votre stock et vos inventaires.
