# Script Vidéo 05 — Gestion des Clients

**Durée estimée : 4-5 minutes**
**Public cible : Vendeurs, Gestionnaires**

---

## SCRIPT AUDIO (à lire pour ElevenLabs)

Dans cette vidéo, nous allons voir comment gérer vos clients dans LOGESCO v2.

### Partie 1 — La liste des clients

Dans le menu principal, cliquez sur le module Clients.

Vous arrivez sur la liste de tous vos clients enregistrés. Pour chaque client, vous voyez son nom, ses coordonnées, et son solde de compte si applicable.

Utilisez la barre de recherche pour trouver rapidement un client par son nom ou son numéro de téléphone.

### Partie 2 — Ajouter un client

Pour ajouter un nouveau client, cliquez sur le bouton Nouveau client.

Le formulaire de création s'ouvre. Remplissez les informations du client.

Commencez par le nom complet du client. C'est l'information la plus importante.

Ajoutez ensuite son numéro de téléphone. Cela vous permettra de le contacter facilement.

Vous pouvez également saisir son adresse email, son adresse physique, et toute autre information utile.

Une fois les informations saisies, cliquez sur Enregistrer.

Le client est maintenant dans votre base de données et vous pouvez le sélectionner lors de vos ventes.

### Partie 3 — La fiche client

Pour consulter la fiche d'un client, cliquez sur son nom dans la liste.

La fiche client vous donne une vue complète de votre relation commerciale avec ce client.

Vous voyez son historique d'achats : toutes les ventes qui lui ont été faites, avec les dates et les montants.

Vous voyez également son solde de compte. Si le client a des achats à crédit non réglés, le solde sera négatif, indiquant qu'il vous doit de l'argent.

### Partie 4 — Le compte client

LOGESCO v2 permet de gérer des comptes clients pour les achats à crédit.

Lorsqu'une vente est faite à crédit, le montant est enregistré dans le compte du client.

Pour consulter le compte d'un client, accédez à sa fiche et cliquez sur l'onglet Compte.

Vous verrez toutes les transactions : les achats à crédit et les paiements effectués.

Pour enregistrer un paiement d'un client qui règle sa dette, cliquez sur Nouveau paiement, saisissez le montant reçu, et confirmez.

Le solde du compte est mis à jour automatiquement.

### Partie 5 — Modifier et gérer les clients

Pour modifier les informations d'un client, accédez à sa fiche et cliquez sur le bouton Modifier.

Apportez vos modifications et enregistrez.

Si vous devez supprimer un client, sachez que cette action est irréversible et que l'historique des transactions associées pourrait être affecté. Procédez avec prudence.

Dans la prochaine vidéo, nous verrons la gestion des fournisseurs et des approvisionnements.
