# Script Vidéo 04 — Gestion du Stock et des Inventaires

**Durée estimée : 6-7 minutes**
**Public cible : Gestionnaires de stock, Administrateurs**

---

## SCRIPT AUDIO (à lire pour ElevenLabs)

Dans cette vidéo, nous allons explorer la gestion du stock dans LOGESCO v2. Un bon suivi du stock est essentiel pour éviter les ruptures et les pertes.

### Partie 1 — Vue d'ensemble du stock

Dans le menu principal, cliquez sur le module Stock ou Inventaire.

Vous arrivez sur la liste de tous vos produits avec leur niveau de stock actuel.

Pour chaque produit, vous voyez : le nom, la catégorie, la quantité disponible, et un indicateur visuel qui vous signale si le stock est normal, bas, ou en rupture.

Les produits dont le stock est inférieur au seuil d'alerte que vous avez défini apparaissent en surbrillance. Cela vous permet d'identifier immédiatement les produits à réapprovisionner.

Utilisez la barre de recherche pour trouver un produit spécifique, ou filtrez par catégorie pour voir uniquement les produits d'une famille donnée.

### Partie 2 — Les mouvements de stock

Chaque entrée ou sortie de marchandise est enregistrée comme un mouvement de stock. Cela vous permet d'avoir un historique complet et de savoir exactement ce qui s'est passé.

Pour consulter les mouvements d'un produit, cliquez sur ce produit dans la liste, puis accédez à l'onglet Mouvements.

Vous verrez la liste de tous les mouvements : les ventes qui ont diminué le stock, les approvisionnements qui l'ont augmenté, et les ajustements manuels.

Chaque mouvement indique la date, le type d'opération, la quantité, et le stock résultant.

### Partie 3 — Ajuster le stock manuellement

Il arrive parfois que vous deviez corriger le stock manuellement, par exemple après un inventaire physique ou pour enregistrer une perte.

Pour faire un ajustement, cliquez sur le produit concerné, puis sur le bouton Ajustement de stock.

Saisissez la nouvelle quantité ou la différence à appliquer, selon l'option choisie.

Indiquez la raison de l'ajustement : correction d'inventaire, perte, casse, ou autre.

Confirmez l'ajustement. Le stock est mis à jour immédiatement et le mouvement est enregistré dans l'historique.

Vous pouvez également faire des ajustements en masse pour plusieurs produits en même temps, grâce à la fonction d'ajustement groupé.

### Partie 4 — Réaliser un inventaire physique

L'inventaire physique vous permet de comparer le stock théorique enregistré dans le logiciel avec le stock réel que vous avez en magasin.

Pour créer un inventaire, accédez à la section Inventaire physique et cliquez sur Nouvel inventaire.

Donnez un nom à votre inventaire, par exemple "Inventaire mensuel de juin", et sélectionnez la date.

Le logiciel génère une liste de tous vos produits avec leur stock théorique.

Parcourez vos rayons et saisissez les quantités réelles que vous comptez pour chaque produit.

Une fois tous les produits comptés, validez l'inventaire. Le logiciel calcule automatiquement les écarts entre le stock théorique et le stock réel.

Vous pouvez ensuite choisir d'appliquer les corrections pour mettre le stock à jour selon les résultats de votre comptage.

### Partie 5 — Les alertes de stock

LOGESCO v2 vous alerte automatiquement lorsqu'un produit atteint son seuil d'alerte.

Ces alertes apparaissent sur le tableau de bord et dans le module stock.

Pour chaque produit en alerte, vous pouvez directement créer une commande fournisseur depuis la liste des alertes, ce qui vous fait gagner du temps.

Dans la prochaine vidéo, nous verrons comment gérer vos clients.

- Montrer les alertes de stock sur le tableau de bord
