## Workflow de production

1. Lire le script et l'adapter si nécessaire
2. Générer l'audio avec ElevenLabs
3. Enregistrer l'écran en suivant les "Notes de réalisation"
4. Assembler audio + vidéo dans CapCut
5. Ajouter sous-titres si souhaité

## Conseils

- Chaque script contient une section "NOTES DE RÉALISATION" qui indique ce qu'il faut montrer à l'écran
- Préparez vos données de démonstration à l'avance (produits, clients, fournisseurs fictifs)
- Enregistrez l'écran en 1080p minimum pour une bonne lisibilité
