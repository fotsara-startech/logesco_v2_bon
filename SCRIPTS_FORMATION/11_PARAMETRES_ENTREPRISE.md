# Script Vidéo 11 — Paramètres de l'Entreprise et Configuration

**Durée estimée : 4-5 minutes**
**Public cible : Administrateurs**

---

## SCRIPT AUDIO (à lire pour ElevenLabs)

Dans cette vidéo, nous allons voir comment configurer les paramètres de votre entreprise dans LOGESCO v2.

### Partie 1 — Les paramètres de l'entreprise

Les paramètres de l'entreprise vous permettent de personnaliser le logiciel avec les informations de votre activité. Ces informations apparaîtront sur vos reçus et documents commerciaux.

Dans le menu principal, accédez aux Paramètres, puis à la section Entreprise.

### Partie 2 — Informations de base

Commencez par saisir le nom de votre entreprise. C'est le nom qui apparaîtra en haut de tous vos reçus.

Ajoutez votre adresse complète : rue, ville, et pays.

Saisissez votre numéro de téléphone et votre adresse email professionnelle.

Si vous avez un numéro de registre de commerce ou un numéro fiscal, saisissez-le dans le champ prévu. Cela peut être obligatoire sur vos documents commerciaux selon la réglementation de votre pays.

### Partie 3 — Logo et slogan

LOGESCO v2 vous permet d'ajouter votre logo d'entreprise sur vos reçus pour un rendu plus professionnel.

Cliquez sur le bouton pour importer votre logo. Sélectionnez le fichier image depuis votre ordinateur. Les formats acceptés sont généralement JPEG et PNG.

Vous pouvez également ajouter un slogan ou une devise d'entreprise qui apparaîtra sous votre nom sur les reçus.

Une fois votre logo et votre slogan configurés, prévisualisez un reçu pour vérifier le rendu.

### Partie 4 — Préférences de vente

Dans les préférences de vente, vous pouvez configurer le comportement du logiciel lors des ventes.

Vous pouvez définir si la TVA est activée par défaut et quel est le taux standard.

Vous pouvez configurer les modes de paiement disponibles pour vos vendeurs.

Vous pouvez également définir si les remises sont autorisées et dans quelles limites.

### Partie 5 — La langue du logiciel

LOGESCO v2 est disponible en plusieurs langues : français, anglais, et espagnol.

Pour changer la langue, accédez aux paramètres et sélectionnez votre langue préférée dans la liste.

Le changement de langue s'applique immédiatement à toute l'interface du logiciel.

Vous pouvez également choisir la langue dans laquelle vos factures et reçus seront générés, indépendamment de la langue de l'interface.

### Partie 6 — La licence et l'abonnement

Pour consulter l'état de votre abonnement, accédez à la section Abonnement dans les paramètres.

Vous verrez la date d'expiration de votre licence et le nombre de jours restants.

Si votre licence est sur le point d'expirer, vous recevrez des notifications pour vous rappeler de la renouveler.

Pour activer une nouvelle licence, cliquez sur Activer une licence et saisissez votre clé de licence.

Gardez votre clé de licence en lieu sûr, car vous en aurez besoin en cas de réinstallation du logiciel.

Ceci conclut notre série de formations sur LOGESCO v2. Vous avez maintenant toutes les clés en main pour utiliser le logiciel efficacement. N'hésitez pas à revoir les vidéos qui vous semblent utiles et à contacter le support si vous avez des questions.
