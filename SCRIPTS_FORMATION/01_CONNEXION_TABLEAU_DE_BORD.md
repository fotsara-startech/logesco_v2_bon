# Script Vidéo 01 — Connexion et Tableau de Bord

**Durée estimée : 3-4 minutes**
**Public cible : Tous les utilisateurs**

---

## SCRIPT AUDIO (à lire pour ElevenLabs)

Dans cette vidéo, nous allons voir comment se connecter à LOGESCO v2 et comment lire le tableau de bord.

### Partie 1 — La connexion

Lorsque vous lancez l'application, vous arrivez sur l'écran de connexion.

Saisissez votre nom d'utilisateur dans le premier champ, puis votre mot de passe dans le second.

Cliquez ensuite sur le bouton de connexion.

Si vos identifiants sont corrects, vous serez redirigé automatiquement vers le tableau de bord principal.

En cas d'erreur, un message s'affiche pour vous indiquer que les informations saisies sont incorrectes. Vérifiez votre nom d'utilisateur et votre mot de passe, puis réessayez.

Si vous avez oublié votre mot de passe, contactez votre administrateur système pour le réinitialiser.

### Partie 2 — Le tableau de bord

Une fois connecté, vous arrivez sur le tableau de bord. C'est votre centre de contrôle.

En haut de l'écran, vous trouvez les indicateurs clés de votre activité : le chiffre d'affaires du jour, le nombre de ventes réalisées, et le bénéfice estimé.

Plus bas, vous avez un graphique qui représente l'évolution de vos ventes sur les derniers jours. Cela vous permet de visualiser rapidement les tendances de votre activité.

Sur le côté, vous trouverez un résumé de votre comptabilité : les revenus, les dépenses, et la marge bénéficiaire.

Le tableau de bord affiche également un indicateur de session de caisse. Si une session est ouverte, vous le verrez ici. Si aucune session n'est active, pensez à en ouvrir une avant de commencer à enregistrer des ventes.

En bas de l'écran, vous avez accès aux activités récentes : les dernières ventes, les derniers mouvements de stock, et les alertes importantes comme les produits en rupture de stock.

Enfin, si votre abonnement approche de son expiration, une notification s'affichera sur le tableau de bord pour vous en informer à temps.

### Partie 3 — La navigation

Pour naviguer dans le logiciel, utilisez le menu principal situé sur le côté gauche de l'écran.

Chaque icône correspond à un module : les ventes, le stock, les produits, les clients, les fournisseurs, la caisse, les rapports, et les paramètres.

Vous pouvez cliquer sur n'importe quelle icône pour accéder directement au module correspondant.

Dans la prochaine vidéo, nous allons voir comment gérer vos produits et vos catégories.
