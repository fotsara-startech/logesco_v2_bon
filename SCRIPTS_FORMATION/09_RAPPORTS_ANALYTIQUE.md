# Script Vidéo 09 — Rapports et Analytique

**Durée estimée : 4-5 minutes**
**Public cible : Gestionnaires, Dirigeants**

---

## SCRIPT AUDIO (à lire pour ElevenLabs)

Dans cette vidéo, nous allons voir comment utiliser les rapports et les outils d'analytique de LOGESCO v2 pour prendre de meilleures décisions.

### Partie 1 — Le module Rapports

Dans le menu principal, accédez au module Rapports.

LOGESCO v2 propose plusieurs types de rapports pour couvrir tous les aspects de votre activité.

### Partie 2 — Le rapport de stock

Le rapport de stock vous donne une photographie complète de votre inventaire à un instant donné.

Vous verrez la liste de tous vos produits avec leur quantité en stock, leur valeur d'achat, et leur valeur de vente.

Ce rapport est utile pour évaluer la valeur totale de votre stock et identifier les produits qui immobilisent le plus de capital.

Vous pouvez filtrer par catégorie et exporter le rapport pour vos archives ou votre comptable.

### Partie 3 — Le rapport des ventes

Le rapport des ventes vous donne le détail de toutes vos transactions sur une période choisie.

Sélectionnez la période qui vous intéresse : aujourd'hui, cette semaine, ce mois, ou une plage de dates personnalisée.

Vous verrez le nombre de ventes, le chiffre d'affaires total, les remises accordées, et le montant net encaissé.

Ce rapport vous permet également de voir les ventes par mode de paiement : combien en espèces, combien par virement, et combien à crédit.

### Partie 4 — Le rapport des remises

Le rapport des remises vous montre toutes les réductions accordées à vos clients sur une période donnée.

Cela vous permet de contrôler votre politique de remises et de vous assurer qu'elles restent dans des limites raisonnables.

### Partie 5 — Le rapport d'activité

Le rapport d'activité est un rapport synthétique qui résume l'ensemble de votre activité commerciale.

Il combine les ventes, les achats, les dépenses, et vous donne une vue d'ensemble de la santé de votre entreprise.

### Partie 6 — L'analytique produits

Pour aller encore plus loin, accédez au module Analytique depuis le menu principal.

L'analytique produits vous montre les performances de chaque produit dans votre catalogue.

Vous pouvez voir quels sont vos produits les plus vendus, ceux qui génèrent le plus de chiffre d'affaires, et ceux qui ont les meilleures marges.

Sélectionnez la période d'analyse : les 7 derniers jours, les 30 derniers jours, les 90 derniers jours, ou une période personnalisée.

Les graphiques vous permettent de visualiser les tendances et d'identifier rapidement les produits phares de votre activité.

Ces informations sont précieuses pour décider quels produits mettre en avant, lesquels réapprovisionner en priorité, et lesquels envisager de retirer de votre catalogue.

### Partie 7 — Exporter les rapports

Tous les rapports de LOGESCO v2 peuvent être exportés.

Cliquez sur le bouton d'export depuis n'importe quel rapport pour obtenir un fichier PDF ou Excel.

Ces exports sont utiles pour partager les données avec votre comptable, pour vos archives, ou pour vos réunions de gestion.

Dans la prochaine vidéo, nous verrons la gestion des utilisateurs et des droits d'accès.
