# Script Vidéo 02b — Import et Export des Produits via Excel

**Durée estimée : 5-6 minutes**
**Public cible : Gestionnaires, Administrateurs**

---

## SCRIPT AUDIO (à lire pour ElevenLabs)

Dans cette vidéo, nous allons voir comment importer et exporter votre catalogue de produits à partir d'un fichier Excel dans LOGESCO v2.

Cette fonctionnalité est particulièrement utile dans deux situations : lorsque vous démarrez avec le logiciel et que vous avez déjà un catalogue existant à intégrer, ou lorsque vous souhaitez ajouter ou modifier plusieurs produits à la fois sans passer par le formulaire un par un.

---

### Partie 1 — Accéder à la fonction Import / Export

Dans le module Produits, cliquez sur le bouton du menu en haut a droite de la page, dans le menu qui apparait, cliquez sur  Import / Export pour accéder à cette fonctionnalité.

Vous arrivez sur une page qui vous propose deux options : importer des produits depuis un fichier Excel, ou exporter votre catalogue existant.

---

### Partie 2 — Télécharger le template

Avant de pouvoir importer des produits, vous avez besoin du template. Le template est un fichier Excel fourni par le logiciel qui contient déjà les bons en-têtes de colonnes, dans le bon ordre, correspondant exactement aux champs du formulaire de création de produit.

Pour obtenir ce template, cliquez sur le bouton Télécharger le template.

Le fichier est automatiquement téléchargé dans le répertoire Documents de votre ordinateur. Allez dans vos Documents et ouvrez ce fichier avec Excel.

Vous verrez que la première ligne contient les en-têtes : référence, nom du produit, description, prix de vente, prix d'achat, remise maximale, code-barres, catégorie, seuil de stock minimum, prestation de service, gestion des dates de péremption, et produit actif.

Chaque colonne correspond exactement à un champ que vous remplissez lors de la création manuelle d'un produit. Vous connaissez déjà ces champs, nous les avons détaillés dans la vidéo précédente.

---

### Partie 3 — Remplir le template

Maintenant, remplissez le template avec vos produits. Chaque ligne correspond à un produit.

Voici les règles importantes à respecter.

Ne modifiez jamais les en-têtes de la première ligne. Le logiciel les utilise pour reconnaître chaque colonne. Si vous changez un en-tête, l'import échouera.

Le nom du produit et le prix de vente sont obligatoires pour chaque ligne. Sans ces deux informations, la ligne sera rejetée.

Pour la référence, vous pouvez laisser la cellule vide. Le logiciel générera automatiquement une référence unique pour chaque produit sans référence, exactement comme lors de la création manuelle.

Pour les colonnes "Prestation de service", "Gestion des dates de péremption", et "Produit actif", utilisez les valeurs indiquées dans le template. En général, il s'agit de "oui" ou "non".

Pour la catégorie, saisissez exactement le nom de la catégorie telle qu'elle existe déjà dans le logiciel. Si la catégorie n'existe pas, elle sera cree automatiquement lors de l'import.

Une fois votre fichier rempli, enregistrez-le au format Excel avec l'extension .xlsx.

---

### Partie 4 — Importer les produits

Retournez sur la page Import / Export du logiciel.

Cliquez sur le bouton Importer.

Une fenêtre s'ouvre pour vous permettre de sélectionner votre fichier. Naviguez jusqu'à vos Documents, sélectionnez le template que vous venez de remplir, et confirmez.

Le logiciel analyse votre fichier et vous présente un aperçu des données qui vont être importées. Vérifiez que les colonnes sont bien reconnues et que les données semblent correctes.

Si tout est en ordre, confirmez l'import.

Le logiciel traite chaque ligne et crée les produits correspondants. Une fois terminé, un rapport s'affiche avec le nombre de produits importés avec succès et les éventuelles erreurs ligne par ligne.

Si des erreurs sont signalées, corrigez les lignes concernées dans votre fichier Excel et relancez l'import.

---

### Partie 5 — Exporter les produits

L'export vous permet de télécharger l'ensemble de votre catalogue sous forme de fichier Excel.

Cliquez sur le bouton Exporter. Le logiciel génère le fichier et vous propose de le télécharger.

Ce fichier est utile pour faire une sauvegarde de votre catalogue, partager votre liste de produits.

---

### Partie 6 — Bonnes pratiques

Avant d'importer un grand catalogue, testez d'abord avec un petit fichier de cinq à dix produits pour vérifier que tout fonctionne correctement.

Faites toujours un export de sauvegarde avant un import massif, pour pouvoir vous référer à l'état précédent si nécessaire.

L'import via template est la façon la plus rapide de démarrer avec LOGESCO v2 lorsque vous avez un catalogue de plusieurs dizaines ou centaines de produits à intégrer.

---

## NOTES DE RÉALISATION

- Montrer le bouton Import/Export dans le module Produits
- Cliquer sur "Télécharger le template" et montrer le fichier qui apparaît dans le dossier Documents
- Ouvrir le fichier Excel et zoomer sur les en-têtes pour les rendre lisibles
- Montrer un template déjà rempli avec 3-5 produits exemples préparés à l'avance
- Lancer l'import et montrer le rapport de résultat
- Vérifier que les produits importés apparaissent dans la liste
- Montrer rapidement l'export en fin de vidéo
