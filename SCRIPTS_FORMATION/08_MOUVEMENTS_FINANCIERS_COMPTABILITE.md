# Script Vidéo 08 — Mouvements Financiers et Comptabilité

**Durée estimée : 5-6 minutes**
**Public cible : Gestionnaires, Comptables**

---

## SCRIPT AUDIO (à lire pour ElevenLabs)

Dans cette vidéo, nous allons explorer la gestion des mouvements financiers et le tableau de bord comptable de LOGESCO v2.

### Partie 1 — Les mouvements financiers

Les mouvements financiers vous permettent d'enregistrer toutes les transactions d'argent qui ne sont pas directement liées à une vente ou un approvisionnement. Par exemple : le paiement d'un loyer, l'achat de fournitures de bureau, ou une rentrée d'argent exceptionnelle.

Dans le menu principal, accédez au module Mouvements financiers.

Vous voyez la liste de tous les mouvements enregistrés avec leur date, leur type, leur catégorie, et leur montant.

### Partie 2 — Enregistrer un mouvement

Pour enregistrer un nouveau mouvement, cliquez sur le bouton Nouveau mouvement.

Choisissez d'abord le type de mouvement : entrée d'argent ou sortie d'argent.

Sélectionnez ensuite la catégorie. Les catégories vous permettent de classer vos dépenses et revenus. Par exemple : loyer, salaires, électricité, ou recettes diverses.

Saisissez le montant du mouvement.

Ajoutez une description pour préciser la nature de la transaction. Par exemple : "Paiement loyer mois de juin" ou "Achat matériel de bureau".

Sélectionnez la date du mouvement. Par défaut, c'est la date du jour.

Cliquez sur Enregistrer pour valider.

Le mouvement est maintenant enregistré et sera pris en compte dans vos rapports financiers.

### Partie 3 — Gérer les catégories de dépenses

Pour organiser vos mouvements financiers, vous pouvez créer des catégories personnalisées.

Accédez à la section Catégories de dépenses dans les paramètres ou depuis le module des mouvements.

Créez des catégories qui correspondent à votre activité : charges fixes, charges variables, investissements, et ainsi de suite.

Des catégories bien organisées vous permettront d'analyser vos dépenses plus facilement.

### Partie 4 — Le tableau de bord comptable

LOGESCO v2 dispose d'un tableau de bord comptable qui vous donne une vue synthétique de votre situation financière.

Accédez au module Comptabilité depuis le menu principal.

Vous verrez les indicateurs clés : le chiffre d'affaires total, les dépenses totales, le bénéfice net, et la marge bénéficiaire.

Le tableau de bord vous permet de filtrer ces données par période : aujourd'hui, cette semaine, ce mois, ou une période personnalisée.

Vous verrez également une analyse par catégorie qui vous montre où va votre argent et d'où il vient.

### Partie 5 — Les rapports financiers

Pour aller plus loin dans l'analyse, accédez au module Rapports.

Le rapport des mouvements financiers vous donne le détail de toutes vos transactions sur une période donnée.

Vous pouvez filtrer par type de mouvement, par catégorie, ou par date.

Ces rapports peuvent être exportés en PDF ou en Excel pour votre comptable ou pour vos archives.

Le rapport d'activité vous donne un résumé global de votre activité commerciale : ventes, achats, marges, et évolution dans le temps.

Dans la prochaine vidéo, nous verrons les rapports et l'analytique produits.
