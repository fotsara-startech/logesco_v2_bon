PROBLÈME:
  ❌ Vente prend 20 secondes (timeout Flutter)
  ❌ Synchronisation bloque la réponse HTTP

CAUSE:
  La sync manuelle utilisait await et bloquait la réponse.
  Le client Flutter attendait que TOUTE la sync soit terminée.

CORRECTION:
  ✅ Utilisation de setImmediate() pour sync asynchrone
  ✅ Réponse HTTP envoyée IMMÉDIATEMENT
  ✅ Sync exécutée en arrière-plan

setImmediate() exécute le code APRÈS la boucle d'événements:

  1. Transaction SQLite (100ms)
  2. Réponse HTTP envoyée → Client reçoit immédiatement ✅
  3. setImmediate() planifie la sync
  4. Sync s'exécute en arrière-plan
  5. Données synchronisées vers Neon

Le client ne attend PAS la sync!

┌──────────────────────────────────────────────────────────────────┐
│ ⚠️  NOTE IMPORTANTE                                              │
└──────────────────────────────────────────────────────────────────┘

La sync se fait APRÈS la réponse HTTP:

  ✅ Vente enregistrée localement immédiatement
  ✅ Client reçoit confirmation sans attendre
  ✅ Sync vers Neon en arrière-plan
  ⚠️  Si sync échoue, vente quand même créée localement
  ✅ Sync retentée au prochain cycle (queue persistante)

C'est le comportement IDÉAL pour une application offline-first!
