  N'EXISTE PAS dans la table mouvements_stock.

ERREUR:
  Unknown argument `dateModification`. Available options are marked with ?.

CAUSE:
  La table mouvements_stock est une table d'historique (append-only).
  Elle n'a que "date_mouvement", pas "date_modification".

CORRECTION APPLIQUÉE:
  ✅ Changé orderBy: { dateModification } → orderBy: { id }
  ✅ Retiré date_modification des données de sync
  ✅ Mis à jour prisma-sync-hooks.js

     ms.id,
     ms.produit_id,
     p.nom as produit,
     ms.type_mouvement,
     ms.changement_quantite,
     ms.date_mouvement,
     sb.quantite_disponible as stock_actuel
   FROM mouvements_stock ms
   JOIN produits p ON p.id = ms.produit_id
   LEFT JOIN stock_boutiques sb ON sb.produit_id = ms.produit_id
   WHERE ms.date_mouvement > NOW() - INTERVAL '5 minutes'
   ORDER BY ms.id DESC;
