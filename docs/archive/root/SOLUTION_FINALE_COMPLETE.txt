EXPLICATION TECHNIQUE POUR LE DEVELOPPEUR :
============================================

Probleme 1 : Guillemets manquants
----------------------------------

Le code Flutter generait des scripts CMD comme ceci :

  INCORRECT :
    SET LOGESCO_DATA_DIR=C:\Users\André Brandone F\...

  CORRECT :
    SET "LOGESCO_DATA_DIR=C:\Users\André Brandone F\..."

Sans guillemets, Windows interprete :
  - SET LOGESCO_DATA_DIR=C:\Users\André
  - Puis essaie d'executer : Brandone F\...
  → Erreur : commande introuvable

Solution : Ajouter des guillemets dans backend_service.dart (DEJA FAIT).

Probleme 2 : Multiples instances Node.js
-----------------------------------------

Scenario typique :
  1. Client execute diagnose-backend-startup.bat
     → Lance un backend sur port 8080
  2. Client execute force-recreate-scripts.bat
     → Lance un DEUXIEME backend → conflit
  3. Client lance LOGESCO
     → Essaie de lancer un TROISIEME backend → echec

Le premier backend continue de tourner en arriere-plan et bloque le port.

Solution : Tuer TOUS les processus Node.js avant de lancer LOGESCO.
