================================================================================
           SOLUTION IMMEDIATE - DEMARRAGE AUTOMATIQUE LOGESCO
================================================================================

VOTRE PROBLEME :
Le logiciel reste bloque sur "Demarrage du serveur..." pendant longtemps.

CAUSE :
Votre nom d'utilisateur Windows contient un espace et un accent ("André 
Brandone F"), ce qui empeche les scripts de demarrage de fonctionner.

SOLUTION EN 2 ETAPES (2 MINUTES) :
===================================

ETAPE 1 : Fermez completement LOGESCO
--------------------------------------
Si l'application est ouverte, fermez-la.

ETAPE 2 : Executez le script de correction
-------------------------------------------
Double-cliquez sur ce fichier : force-recreate-scripts.bat

Le script va :
  [1] Detecter votre installation
  [2] Recreer les scripts de demarrage (avec les bons guillemets)
  [3] Tester le demarrage
  [4] Afficher "SCRIPTS RECREES ET TESTES AVEC SUCCES !"

Duree : 30-45 secondes

ETAPE 3 : Relancez LOGESCO
---------------------------
Ouvrez LOGESCO normalement.
Le backend devrait maintenant demarrer automatiquement en 15-30 secondes.
L'ecran de connexion s'affichera.

C'EST TOUT !

================================================================================

VERIFICATION :
==============

Pour verifier que tout fonctionne :
  1. L'ecran de connexion apparait en moins de 30 secondes
  2. Vous pouvez vous connecter avec vos identifiants
  3. Le logiciel fonctionne normalement

SI CA NE MARCHE PAS :
=====================

1. Verifiez que vous avez bien FERME LOGESCO avant d'executer le script
2. Executez le script diagnose-backend-startup.bat et envoyez le resultat
3. Contactez le support : support@logesco.com

EXPLICATION TECHNIQUE (optionnel) :
====================================

Les chemins Windows avec espaces et accents doivent etre entre guillemets.
Exemple :

  INCORRECT : cd C:\Users\André Brandone F\...
  CORRECT   : cd "C:\Users\André Brandone F\..."

Le script corrige ce probleme en recreant les scripts de demarrage avec
les guillemets corrects.

QUESTIONS FREQUENTES :
======================

Q: Pourquoi ce probleme n'affecte que certains utilisateurs ?
R: Seulement les utilisateurs avec des espaces ou accents dans leur nom 
   d'utilisateur Windows sont affectes. Exemple : "André Brandone F",
   "Marie Claire", "François Martin", etc.

Q: Est-ce que je vais perdre mes donnees ?
R: Non, absolument pas. Le script corrige juste la configuration de 
   demarrage, aucune donnee n'est touchee.

Q: Dois-je faire ca a chaque fois que je lance LOGESCO ?
R: Non, une seule fois suffit. Une fois corrige, le probleme ne reviendra 
   pas (sauf si vous reinstallez l'application).

Q: Le script dit "OK" mais LOGESCO ne demarre toujours pas ?
R: Verifiez votre antivirus. Il peut bloquer les scripts VBS. Ajoutez une 
   exception pour :
   C:\Users\André Brandone F\AppData\Local\LOGESCO\backend\_logesco_start.vbs

Q: Combien de temps ca prend ?
R: Le script prend 30-45 secondes. Le premier demarrage de LOGESCO apres 
   correction prend 15-30 secondes. Les demarrages suivants seront plus 
   rapides (5-10 secondes).
