================================================================================
                      WHAT'S DIFFERENT FROM V1
================================================================================

V1 (OLD - Destructive):
1. Backend starts
2. DELETE entire local database
3. PULL all data from Neon
→ Risk: Data loss if interrupted, slow startup

V2 (NEW - Event Sourcing):
1. Backend starts
2. READ operation_log (journal)
3. REPLAY pending operations to Neon
4. PULL only NEW data (no DELETE)
→ Safe: Immutable journal, fast startup, zero data loss

KEY DIFFERENCE: Instead of erasing history, we PRESERVE it and REPLAY it.
