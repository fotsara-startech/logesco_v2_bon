# Installation du Client LOGESCO - Guide Rapide

## 🚀 Démarrage Rapide (3 étapes)

### Étape 1: Exécuter le script de configuration
```bash
setup-client-reseau.bat
```

Le script vous demandera:
- L'adresse IP du serveur (ex: `192.168.100.101`)
- Le port (par défaut: `8080`)

### Étape 2: Laisser le script tester la connexion
Le script vérifiera que le serveur est accessible.

### Étape 3: Lancer l'application
L'application LOGESCO se lancera automatiquement.

## ✅ Vérification

Si tout fonctionne:
- ✅ L'écran de connexion s'affiche
- ✅ Vous pouvez vous connecter avec `admin` / `admin123`
- ✅ Le dashboard se charge

## ❌ Problèmes?

### L'app ne se connecte pas
1. Vérifiez l'adresse IP du serveur
2. Vérifiez que le serveur est en cours d'exécution
3. Vérifiez que le firewall n'est pas bloquant
4. Relancez le script `setup-client-reseau.bat`

### Le script dit que le serveur n'est pas accessible
1. Vérifiez l'adresse IP
2. Vérifiez le port (généralement 8080)
3. Vérifiez que le serveur est en cours d'exécution
4. Vérifiez le firewall
