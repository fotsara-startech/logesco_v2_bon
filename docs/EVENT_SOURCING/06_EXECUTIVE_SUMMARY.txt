================================================================================
                          HOW IT WORKS (SIMPLE)
================================================================================

OLD PROCESS (Dangerous):
1. Backend starts
2. DELETE entire local database
3. PULL everything from Neon
4. Run queries
⚠️ Risk: Data loss if interrupted

NEW PROCESS (Safe):
1. Backend starts
2. Read operation_log (journal of all events)
3. REPLAY pending operations to Neon
4. PULL only new data since last sync (no DELETE)
5. Run queries
✅ Safe: Nothing is ever deleted, operations are replayed

WHEN USER MAKES A SALE:
OLD:
- Create sale in local DB
- Add to enqueue table (separate table)
- Hope it syncs later

NEW:
- Create sale in local DB
- logOperation('ventes', 'INSERT', sale, userId)
  ↓
- Automatically logged in operation_log
  ↓
- Automatically replayed to Neon
  ↓
- Complete audit trail (who, when, what)
